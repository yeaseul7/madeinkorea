# 진진잡기 에셋

참고 시안의 따뜻한 한국 시골 마당과 캐주얼 게임 그림체에 맞춘 게임 전용 에셋.

## 구성

- `characters.png`: 투명 2×2 캐릭터 아틀라스. 좌상 진진이, 우상 백구, 좌하 황구, 우하 흑구.
- `props.png`: 투명 2×2 소품 아틀라스. 좌상 항아리, 우상 빈 나무 간판, 좌하 뼈다귀, 우하 발바닥 보상 효과.
- 배경: `/images/jinjin-yard-painted.png`.

아틀라스는 CSS `background-size: 200% 200%`와 각 셀의 `background-position`으로 사용합니다. 점수·시간·문구는 이미지에 굽지 않고 HTML로 표시합니다.

## 연출

- 등장/숨기기: 캐릭터 레이어의 translateY.
- 정답: +100/+150/+200 점수 및 발바닥 효과.
- 오답: −50점 및 콤보 초기화. 참고 시안의 −100은 사용하지 않습니다.
- 5회·10회 연속 이후 배율: ×1.5 / ×2.

AI로 생성한 게임용 아트. 역사 자료나 실제 진돗개 사진으로 사용하지 않습니다.
